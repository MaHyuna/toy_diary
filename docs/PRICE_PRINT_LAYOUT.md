# 요금표 인쇄 배치

2026-11-08: 사용자가 제공한 최초 요금표를 기준으로 제목 옆 안내, 아래 견종 설명, 하단 추가금액·고양이 미용 2열 구조를 유지한다. 가격·문구·로고·색 등 저장된 원본은 수정하지 않는다.

- 꽃 중심과 제목 첫 줄의 실제 글자 영역 중심을 맞춘다. 고정 기준선 오프셋을 쓰지 않는다.
- 매트릭스 안내는 제목 옆에 공간이 있으면 표시하고 긴 문구는 아래로 내려 겹침을 피한다.
- 목록은 항목명과 금액의 영역을 나누고, 금액 열의 오른쪽 끝을 통일한다. 항목명·복수 금액·안내문은 각 영역 안에서 줄바꿈한다.
- 항목명과 금액의 줄 수를 함께 측정해 행 높이를 늘리고, 양쪽 글자를 행 중앙에 정렬한다. 닫는 괄호만 한 줄에 남지 않게 한다.
- 새 문서는 A4가 기본이다. 미리보기 상단과 내보내기 메뉴에서 A4/긴 이미지를 전환한다. 기존 문서에 저장된 형식은 유지한다.
- `planning/pricelist.html?paper=a4`는 저장된 내용을 유지하면서 용지만 A4로 전환한다. 적용 후 URL의 paper 매개변수를 제거해 이후 사용자의 형식 선택을 강제하지 않는다.
- A4는 반드시 한 장이다. 900×1273 논리 좌표, 다운로드는 1800×2546px PNG 한 장이다. 페이지 분할·다음 쪽·전체 페이지 ZIP을 제거했다.
- 한 장보다 길면 출력용 복사본에서 섹션 간격과 표 행 여백을 먼저 줄인다. 그래도 넘치면 전체 내용을 같은 비율로 축소해 테두리 안에 배치한다. 종이·테두리 크기는 유지하며 로고·모든 항목·금액·안내를 빠짐없이 담는다. 저장된 디자인·문구·금액은 변경하지 않는다.
- 출력에 맞춘 요소 좌표를 편집 선택 영역에도 적용한다. 확대/수정 후에도 같은 한 장을 미리보기·다운로드·고객 게시에 사용한다.
- 실제 인쇄 시 A4(210×297mm) 용지를 선택해 용지에 맞춰 출력한다. PNG는 PDF와 달리 물리적 용지 설정을 내장하지 않는다.

검증: `npm run test:studio`, `python tests/browser_price_print.py`, `python tests/browser_price_publication.py`. 브라우저 테스트는 실제 Jua 글꼴의 글자 영역, 꽃 중심, 양쪽 목록 글자 중심, 긴 항목·복수 금액·안내문, A4 PNG 바이너리 규격, 긴 표도 한 장에서 행 보존, 기존 문서 형식/브랜드/가격/색 보존을 검사한다. 실제 운영 DB에는 접근하지 않는다.

2026-11-12: 빈 매장명은 대체 문구와 여백 없이 숨긴다. 저장 용량 이내의 PNG/JPEG/WebP 로고는 원본을 유지하고, 큰 파일만 최대 1800px로 축소한다. 로고 표시 크기는 40–240이다.

텍스트 선택 시 오른쪽 ↔ 손잡이로 너비를 조절한다. 제목·견종·설명·목록 항목·매장 안내의 너비를 `canvas.styles[id].width`에 저장하며, 영역 안에서 줄바꿈하고 뒤 행과 섹션의 위치를 다시 계산한다. 금액 영역을 침범하지 않도록 최대 너비를 제한한다. 방향키는 10, Shift+방향키는 1 단위로 조절한다. 드래그 한 번은 되돌리기 한 번에 대응한다.

새 문서는 사용자가 제공한 1000025787.png의 최신 요금으로 시작한다. 기존 브라우저 문서는 자동으로 덮어쓰지 않는다. ‘최신 요금표 적용’은 변경 전 JSON 백업을 내려받고 최신 요금·디자인을 적용하며, 매장 이름·로고를 유지한다. 이미지의 ‘매장로고 위치’는 자리 표시이므로 실제 문구로 넣지 않는다.

추가 검증: `python tests/browser_price_resize.py`에서 데스크톱 마우스·실제 터치 이벤트, 너비 저장·복원, 되돌리기, 템플릿 적용 전 백업을 검사한다.
