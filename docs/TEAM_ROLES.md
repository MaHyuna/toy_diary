# 프로젝트 역할

사용자가 지정한 역할은 다음과 같습니다.

- **로고스 · 기획/UX**: 사장님과 고객의 목적, 화면 흐름, 정보 우선순위, 빈 상태·실패 상태 및 조작 규칙을 정의합니다.
- **카리스 · 디자이너**: 화면 구조와 비율, 타이포그래피, 색상, 여백, 컴포넌트·상태·모션의 시각 언어를 책임집니다.
- **누스 · 개발**: 기획과 디자인을 구현하고, 데이터 보존·키보드/터치·화면 전환·반응형·저장 동작을 검증합니다.

역할별 작업은 하나의 사용자 흐름을 기준으로 통합합니다. 화면이 동작한다는 사실과 실제 사용성이 좋다는 판단은 구분합니다. 기존 사용자 지시인 드래그 제거, 명시적 편집 진입, 모바일 캘린더 우선, 고객/운영자 화면 구분을 유지합니다.
