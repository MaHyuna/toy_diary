# 애견미용 업무 조사와 설계 근거

확인일: **2026-10-28 (한국 시간)**

## 이번 조사에서 확인한 범위

공개 자료를 직접 읽어 기본 미용 절차와 샴푸 제조사의 사용 지침을 확인하려고 했으나, 환경의 네트워크 프록시가 아래 요청을 모두 차단했습니다. **외부 페이지 본문과 제목을 확보하지 못했으며, 업계 절차나 특정 제품의 희석률을 외부 자료로 검증했다고 주장할 수 없습니다.**

일반 실행에서는 `Operation not permitted`, 승인된 읽기 전용 요청에서는 `Tunnel connection failed: 403 Forbidden`이 발생했습니다. HTTP 응답 본문까지 도달하지 못했으므로 이 결과를 사이트 자체의 접근 거부나 페이지 삭제로 해석하지 않습니다.

조사를 이어가려면 환경의 네트워크 설정에서 위 대상 도메인 접근이 가능해야 합니다. 접근 후 공식 홈페이지의 탐색 경로로 실제 문서를 확인하고, 제목·주소·확인일·해당 문장을 기록합니다. 다른 출처의 설명을 제조사의 공식 희석 지침으로 대체하지 않습니다.

## 사용자가 확정한 요구사항

- 현재는 운영자 한 명이 사용하고, 이후 직원 여러 명으로 확장할 수 있어야 합니다.
- 예약, 정산, 매출·지출 장부가 필요합니다.
- 요금은 서비스 기본가, 견종, 몸무게, 입질·엉킴·추가 작업 등의 사유를 반영합니다.
- 보호자와 반려견을 반복해서 관리할 고객관리대장이 필요합니다.
- 샴푸 비용을 기록하고 파악해야 합니다.
- 네이버 예약 연동은 이후 단계입니다.

## 검증을 더 해야 하는 업무 흐름

다음은 사용자 요구를 기능으로 연결하기 위한 **설계안**입니다. 국내 애견미용업계 전체의 표준이나 법적 의무로 확인한 내용이 아닙니다.

| 단계 | 기록할 정보 | 기능에 반영할 이유 |
| --- | --- | --- |
| 상담·고객 등록 | 보호자 이름·연락처, 반려견 이름·견종·몸무게·생년 정보, 보호자가 알려준 피부 민감성·알레르기·행동 주의점, 선호 스타일 | 한 보호자의 여러 반려견을 구분하고 재방문 때 정보를 재사용 |
| 예약·사전 견적 | 서비스·일시·소요 시간·담당자·예상 금액과 항목별 산출 내역 | 일정 충돌 방지와 금액 설명 |
| 방문 상태 확인 | 당일 몸무게·털 엉킴·추가 작업·보호자와 확인한 금액 변경 | 사전 견적과 실제 작업의 차이를 기록 |
| 목욕·미용 기록 | 사용 제품, 사용량, 그날의 작업 메모와 스타일 | 재방문 참고와 소모품 비용 파악 |
| 인계·정산 | 실제 결제액·수단·일자, 작업 결과 메모 | 방문 이력과 현금 흐름 연결 |
| 재방문 관리 | 반려견별 예약·서비스·견적·결제·메모 이력 | 같은 설명을 반복 입력하지 않고 이전 작업을 조회 |

건강 관련 항목은 보호자가 전달한 정보와 미용사가 관찰한 주의사항을 기록하는 범위입니다. 앱이 진단하거나 치료·제품 적합성을 결정하지 않습니다. 필수 동의 항목이나 보관 기간은 국내 적용 기준을 별도로 확인해야 합니다.

## 샴푸 비용의 세 가지 의미

**고객에게 청구하는 금액**, **샴푸를 살 때 실제 지급한 금액**, **이번 방문에 사용한 샴푸의 추정 원가**를 구분합니다.

| 구분 | 예시 | 장부 처리 |
| --- | --- | --- |
| 고객 청구 추가금 | 특수 샴푸 사용 추가요금 | 예약 견적의 추가 항목. 정산 시 매출에 포함 |
| 구매 지출 | 샴푸 한 통 구입 | 실제 지출일에 가계부에 한 번 기록 |
| 방문별 사용 원가 | 한 통 중 이번 방문에서 쓴 분량 | 원가 참고 자료. 구매 지출에 더해 현금 지출로 다시 차감하지 않음 |

제품명을 등록했다고 구매 지출을 자동 발생시키지 않습니다. 같은 제품을 여러 번 구매할 수 있고, 실제 지급일과 금액은 제품의 기준 단가와 다를 수 있기 때문입니다. 제품 기준 단가를 변경해도 이전 방문의 원가 기록이 바뀌지 않도록 당시 단가·사용량을 보존합니다.

### 단위와 계산

기본 단위는 **원, mL**입니다. 용량이 L로 표시되어 있으면 `1 L = 1,000 mL`로 변환합니다. 미국 갤런·영국 갤런·fl oz는 서로 다를 수 있으므로 단위 종류를 확인하지 않은 채 같은 숫자로 입력하지 않습니다. 실제 구매 가격과 제조사 포장 용량을 사용합니다.

원액 사용량을 직접 입력할 때:

`방문별 추정 원가 = 한 통의 기준 구입금액 ÷ 한 통의 원액 용량(mL) × 사용 원액량(mL)`

희석액 사용량에서 원액량을 구하려면 제조사가 표시한 비율의 의미를 먼저 확인해야 합니다. **원액 1 : 물 N**이라는 뜻이 확인된 경우에만:

`사용 원액량 = 사용 희석액량 ÷ (1 + N)`

예를 들어 원액 1 : 물 9로 만든 희석액 100mL에는 원액 10mL가 들어갑니다. 1,000mL 한 통의 기준 가격이 30,000원이면 해당 원액의 추정 원가는 300원입니다. **이 숫자는 계산 설명용 가정이며 특정 제품의 권장 희석률·가격이 아닙니다.** 희석배수를 확인하지 못한 제품에는 임의의 권장값을 넣지 않습니다.

## 외부 자료에서 추가로 확인할 항목

- 미용 전 상담·상태 확인·작업·인계 과정에 실제로 포함하는 단계
- 견종뿐 아니라 크기·털 상태·작업 시간 등이 요금에 영향을 주는지, 추가 작업의 안내 방식
- 사용하려는 샴푸의 정확한 제품명, 포장 용량, 제조사 지침의 희석 비율과 단위 정의
- 제조사가 설명하는 사용 대상·주의사항·혼합 후 보관 지침
- 국내 운영에 필요한 고객 정보 동의·보관·삭제 기준과 실제 매장 업무 방식

확인 전까지 위 항목은 조사 완료 사실로 표시하지 않습니다. 첫 구현은 사용자에게 확인된 업무와 명시적인 수동 입력·계산을 중심으로 진행합니다.
