# 공유용 화면 흐름 프로토타입

주소: `/prototype/` (Pages에서는 `/toy_diary/prototype/`). 기존 서비스와 분리된 Vite 엔트리다. Claude 공유 링크는 확인 환경에서 로그인 요청만 표시되어 내부를 참조하지 못했다. 현재 구현을 기준으로 화면 흐름보드와 클릭형 미리보기를 함께 제공한다.

- 사장님 예약 → 미용 전후 기록 → 공개 → 결제, 예약 취소 분기.
- 요금 목록 → 상세 → 등록·수정 → 이력 → 복원, 삭제·미저장 변경·저장 충돌 분기.
- 고객 홈 → 요금표 → 예약 신청 확인 → 접수, 미용수첩.
- 공지 목록 → 상세 → 작성·수정·삭제.

32개 화면, 4개 사용자 흐름. 실제 UI의 필드를 단순화한 검토용 모형이다. 자동 확정 알림은 미구현 제안으로 별도 표시한다. 온라인 예약은 요금 연결 설정을 마친 매장을 가정한다.

공식 Spectrum 2 컴포넌트는 기존 Provider를 재사용한다. 프로토타입 전용 레이아웃과 화면 모형 스타일은 `src/ui/prototype.css`에 분리했다. 일반 화면의 디자인을 교체하지 않는다.

URL fragment에 flow, screen, mode를 기록해 특정 화면을 공유하거나 새로고침·뒤로가기를 사용할 수 있다. 입력값은 React 메모리에만 남고 새로고침 시 초기화된다. API 요청·브라우저 앱 저장소 접근은 하지 않는다. 일부 예시 입력/결과만 연동하며 모든 기능의 동작 검증은 실제 서비스에서 진행한다.

검증: 모든 화면의 첫 동작 및 모든 연결 대상 유효성, 320/390/1440px 가로 넘침, 직접 화면 링크/재접속, 예시 금액 저장, 실제 API·저장소 비접근.
