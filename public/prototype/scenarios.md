- 해당 분류의 새 예약 견적은 사용할 수 없지만 기존 예약 기록은 유지됩니다.

**동작 → 다음 화면·상태**

- 유지하기 → 요금 분류 상세
- 분류 삭제 확정 → 요금 분류 목록

### 공지 작성과 고객 공개

공지 목록에서 작성·상세·수정·삭제를 구분하고 고객 공개를 선택합니다.

#### 공지 목록

담당: 사장님 / 유형: 목록 / 기존 구현 기반

**목적**

- 공개·비공개 공지를 검색하고 관리합니다.

**진입 경로**

- 공지 상세 → 공지 목록
- 새 공지 쓰기 → 공지 저장
- 새 공지 쓰기 → 작성 취소
- 공지 삭제 확인 → 삭제 확인

**표시·입력 항목**

- 공지 제목·본문과 공개/비공개 상태
- 제목·내용 검색과 공개 상태 필터
- 등록·수정·공개 해제·삭제 대상
- 고객 홈 노출 여부와 저장 결과

**처리·검증 규칙**

- 메뉴를 눌러도 작성 폼이 바로 열리지 않습니다.

**동작 → 다음 화면·상태**

- 11월 휴무 안내 보기 → 공지 상세
- + 공지 쓰기 → 새 공지 쓰기

#### 공지 상세

담당: 사장님 / 유형: 조회 / 기존 구현 기반

**목적**

- 공지 본문과 공개 상태를 확인합니다.

**진입 경로**

- 공지 목록 → 11월 휴무 안내 보기
- 공지 수정 → 수정 저장
- 공지 수정 → 작성 취소
- 공지 삭제 확인 → 공지 유지

**표시·입력 항목**

- 공지 제목·본문과 공개/비공개 상태
- 제목·내용 검색과 공개 상태 필터
- 등록·수정·공개 해제·삭제 대상
- 고객 홈 노출 여부와 저장 결과

**처리·검증 규칙**

- 고객에게 공개된 공지는 고객 홈에서도 보입니다.

**동작 → 다음 화면·상태**

- 공지 수정 → 공지 수정
- 공지 삭제 → 공지 삭제 확인
- 공지 목록 → 공지 목록

**표시·입력 항목**

- 등록·수정·공개 해제·삭제 대상
- 고객 홈 노출 여부와 저장 결과

**처리·검증 규칙**

- 저장하기 전에는 고객 화면에 반영하지 않습니다.

**동작 → 다음 화면·상태**

- 공지 저장 → 공지 목록
- 작성 취소 → 공지 목록
